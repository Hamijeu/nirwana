# Alur Demo

1. **Client:** Landing → Masuk → Client Dashboard → Layanan Saya → Laporkan Gangguan → Isi form → Sukses → Detail tiket.
2. **Admin:** Mode demo Admin → Dashboard → Ticket Gangguan → Detail → Terima tiket baru atau tugaskan teknisi → Ubah status / progress → Selesai → Arsipkan.
3. **Officer:** Mode demo Officer → Pelanggan → Detail pelanggan → Tiket → Detail → Tugaskan teknisi. Menu pengguna dan arsip tidak tersedia.
4. **Technician:** Mode demo Teknisi → Dashboard → Klaim tiket belum ditugaskan → Detail → Mulai pekerjaan → Tambah catatan / status → Selesai.
5. **Pemulihan akun:** Login → Lupa password → Nomor WhatsApp → OTP enam digit → Password baru → Login. Seluruh proses simulasi.
6. **Tambah pelanggan:** Admin/Officer → Pelanggan → Tambah pelanggan → Simpan → Detail pelanggan.
7. **Tambah layanan:** Admin/Officer → Layanan → Tambah layanan → Simpan → Detail layanan.
8. **Import CSV:** Admin/Officer → Import / Export → Pilih CSV → Validasi → Preview → Konfirmasi → Selesai. Jika validasi bermasalah, konfirmasi dinonaktifkan.

Gunakan `Mode demo` untuk berpindah role. Data aksi lokal hilang setelah halaman dimuat ulang.
