# Asumsi dan Konfirmasi yang Diperlukan

Semua contoh di bawah adalah **ASSUMPTION**, bukan ketentuan bisnis yang disahkan.

- Nama, nomor telepon tersamarkan, alamat, wilayah, waktu, voucher, dan tiket adalah data demo fiktif.
- Kategori gangguan opsional: koneksi mati, lambat, tidak stabil, lainnya.
- Nilai prioritas `LOW`, `MEDIUM`, `HIGH`, `CRITICAL` belum memiliki definisi SLA resmi.
- Angka KPI dan grafik dashboard adalah ilustrasi data kecil; rumus final perlu disepakati.
- Kontak resmi, email, alamat kantor, cakupan layanan, dan naskah website publik perlu konfirmasi.
- Perangkat utama teknisi belum ditentukan; UI dirancang mobile first dan tetap berjalan di desktop.
- Import CSV memakai kolom `nama`, `nomor_layanan`, `wilayah`; skema final dan aturan duplikasi perlu konfirmasi.
- Penugasan lebih dari satu teknisi ditampilkan secara visual, tetapi model data demo menyimpan satu teknisi utama.
- Tidak ada harga paket karena scope terbaru melarangnya; versi landing sebelumnya menampilkan harga simulasi.
